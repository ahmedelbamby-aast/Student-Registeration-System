This is a pre-implementation verification guide. It does not run or create application code.

1. Confirm the feature is Approved for Gate A demo implementation as of

2. Review requirements.md and confirm the accepted `DEMO-POC-2026.1` values,
   demo-only authority boundary, and excluded workflows.
3. Verify each functional requirement appears in spec.md and tasks.md.
4. Walk through each acceptance scenario and the 9/12/18-credit boundaries
   with Ahmed acting in the accountable owner perspective.
5. Review data-model.md, the official curriculum provenance, every synthetic
   gap label, and contracts/api.md against upstream dependencies.
6. Run the repository Spec Kit gate script.
7. Verify the Gate A approval record, then execute approved implementation
   tasks in dependency order; preserve later production policy and release
   gates.
