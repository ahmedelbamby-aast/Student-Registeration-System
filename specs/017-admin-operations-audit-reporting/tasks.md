## Evidence Rules

- A red-first task is checkable only when its named test exists, compiles, and
  fails for the expected missing behavior rather than a build, fixture,
  environment, or unrelated failure.
- A delivery task is checkable only after its red-first evidence was observed,
  its named source exists, and every directly linked focused test passes.
- A conformance task for already-delivered upstream behavior may pass on its
  first run; artificial production changes are forbidden merely to force red.
- A document task is checkable only when the named record contains the review
  date, baseline commit, result, and links to the supporting commands or tests.
- The phase evidence commit and matching pushed remote commit ID are recorded in
  `docs/release-evidence/SPEC-017-phase-ledger.md`. No checkbox is evidence by
  itself.
