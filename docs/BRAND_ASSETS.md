| Field | Approved value |

| Accessible name | `Arab Academy for Science, Technology and Maritime Transport` |

Gate A is approved. During frontend implementation, the asset MUST be downloaded
from the authoritative URL, record the retrieval date and SHA-256 digest, and
serve the reviewed local copy. The application MUST NOT depend on a runtime
hotlink. The logo's aspect ratio MUST be preserved and it MUST NOT be
recolored, cropped, stretched, distorted, or used as a source from which to
guess institutional colors or typography. A repeated decorative copy uses an
empty accessible name.
