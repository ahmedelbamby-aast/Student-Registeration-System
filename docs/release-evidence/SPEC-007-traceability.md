This matrix links every SPEC-007 requirement, scenario, route, entity, and
endpoint to executable test source. The matrix validator proves that the set is
complete, has no duplicate IDs, and references existing test classes. It does
not turn a Markdown label into runtime proof: the cited projects must still be
built and executed successfully for the current commit.

## Evidence boundaries

- `ExecutableIdentityJourneys` renders the real Razor components with bUnit,
  exercises native form interactions, sends HTTP requests through a controlled
  handler, and verifies rendered feedback/navigation. It is not a real-browser
  or live-network test.
- `IdentityRuntimeCompositionTests` uses ASP.NET Core TestServer for actual
  middleware/HTTP enforcement of Endpoint10, antiforgery ordering, SQL service
  composition, Production startup guards, and hosted-WASM fallback behavior.
  `IdentityHttpSessionEvidenceTests` adds TestServer coverage for mutation
  antiforgery rejection, logout-cookie expiry, and cross-replica stamp
  invalidation. Neither is a dedicated authorization-handler test of all 16
  endpoints.
- Authorization suites execute the named policies with positive and negative
  principals. Endpoint contract suites verify route-specific anonymous versus
  protected metadata, antiforgery metadata, and named policy attachment.
- Persistence suites use EF Core and the real-SQL fixture for uniqueness,
  single-use transitions, savepoint rollback, audit atomicity, import handoff,
  and final-enabled-Admin races. A skipped SQL prerequisite is not a pass.
- Accessibility evidence is limited to rendered component semantics, visible
  labels/errors, native keyboard-operable controls, and dialog escape/focus
  contracts. No axe scan and no real-browser keyboard audit is claimed.
- NFR-1 is a service-level two-adapter/shared-state login profile. Full
  HTTP/SQL multi-host topology remains a SPEC-018 release concern.
- Production deployment, official AASTMT identity authority, and institutional
  credential/recovery/provisioning approval are not granted by this matrix.
